# 如何分辨好基金、如何管好基金——访谈 103 位基金经理后的思考

> 背景:作者本以写"小剧场段子"为人所知,当下主业是做基金研究(基金经理研究)。2023 年正式访谈了 103 位基金经理。

## 开篇:我见过的基金经理众生相

2023 年访谈的这 103 人中,有当下或过往的当红炸子鸡,有正在被逐渐认知的新星,也有尚未被发掘的大才。他们里面:

- 有坚定思路等待机会的**荒野猎人**;
- 有自以为是的**井底之蛙**;
- 有迷茫、不知自己应当怎样找准定位的**普通人**;
- 有基本功扎实、但需要市场磨练才会有清晰思路的**小蜜蜂**;
- 有空有理念但啥研究都不做的**骗子**;
- 有以为这个市场瞎了的**瞎子**;
- 有"天下皆醉我独醒"的**偏执怪人**;
- 有被市场磨圆之后失去自我、风往哪吹就往哪滚的**皮球**。

本文分两部分,各取所需:

- **第一部分**:如果你想买好基金 → 怎么分辨好的基金经理;
- **第二部分**:如果你想管好基金 → 哪些是你要想清楚的关键问题。

(至于"已经亏钱的基金怎么回本"——想到答案的话请一定告诉我,我也想知道,在线等,有点急。)

## 一、如果你想买好基金

### 关于 alpha 的误解

我们对好基金有一个误解:好基金都应有学术定义的 alpha——涨时比别人多,跌时比别人少,长期相对稳定,回撤可控。

**这是不可能的。** 即使可能,也只是某一阶段可能罢了,没有人能知道 alpha 的状态啥时候结束。我们只能在一个人的 alpha 跑完、甚至被负 alpha 反噬完、亏了大钱之后,才知道这段超额收益已经没了。在这之前,我们只能继续相信它还有 alpha。

> 那为什么它还有 alpha 呢?因为它之前就有 alpha。那为什么它又没有 alpha 了呢?因为它之前的 alpha 没了。

更接地气的说法:为什么老王能成为划线派?因为老王之前的净值线走得好。为什么老王又不是划线派了?因为老王的线走差了。是不是很儿戏?

学术界之所以创造 alpha 这个术语,是因为它研究的是**净值波动的数学现象**,对创造净值的基金是如何管理的则一无所知。

而业界真实的情况是:基金经理作为一个人,赚到手的是**认知的钱**,只不过被每秒都在变化的股价反映出来。

> 一个人能做到的极限是:模糊地知道起点和终点分别是什么样子,如果迷路了、到不了终点又是什么样子。至于中间的路程是上坡还是下坡、哪段是草地哪段是森林哪段要跨河,这不是一个走路的人能控制的。
>
> 翻译过来就是:一个人能做到的极限,是自己知道自己赚的是什么钱、什么时候算赚到了、什么时候是自己判断错了。

### 三位基金经理,选谁?

以下有三位基金经理:

| | 侧重 | 观点举例 |
|---|---|---|
| **A** | 商业逻辑 | 选某支个股,因为这个行业必然会出现一两个巨头整合资源(国外已验证趋势),而这家公司管理能力最强,最有潜力成为巨头 |
| **B** | 竞争逻辑 | 不选这支个股,因为这家公司是老板的一言堂,管理半径有限,不具备整合上下游的能力 |
| **C** | 产业跟踪 | 不太看行业终局,订单好了就涨、订单不好了就跌;涨时什么宏大叙事都会有,跌时什么鬼故事也都能冒出来 |

**我的回答:A、B 都更容易赚钱,排除 C。**

**为什么观点相反的 A 和 B 都可能赚钱?**

1. 基金经理的**预判完全不重要**,因为人类预判不了很远的未来。"行业集中度提高"是一种趋势,"公司管理半径有限"是一种限制,这都对;但事物从来不是一成不变的,所以观点相反不妨碍如何应对——有的行业集中不起来有中国的特殊原因,有的公司就算一言堂也能做成全球第一。
2. A 和 B 探讨到了两个最重要的议题:**行业是否给机会**、**个人(公司)努力是否接得住机会**。这两个问题没法提前给答案,但花精力去验证、去跟踪肯定不会错,大不了跟踪过程中及时修正观点。

> 基金经理最重要的能力,就是**应对能力**;而应对,是需要做好充分准备的。

就 A、B 的话题,理论上我们应该更深入地探讨:为什么这个行业放到中国市场确实存在整合机会;之前为什么没整合、为什么现在适合;整合需要这家公司什么禀赋;如果并购,是给对方更高自由度还是完全并入自家流程;如果管理半径确实有限,是因为老板对哪些关键环节完全不理解……**挖得更深,才能更好地考察他们是否真的勤勉尽责。**

**为什么排除 C?** 因为他很可能不具备识别产业趋势成型或结束的能力。跟踪景气度不应只看边际变化,因为边际变化从来不丝滑——上升期会有 miss 的时候,下行期也会有 beat 的时候。

> 带着整体框架去看一个数据序列,会比不带框架更有方向感,也更知道哪些是关键数据、哪些其实不重要。

**举例("30% 临界点"):** 抓某产品渗透率提升的机会时,常找"30% 临界点"——这个点之前,渗透率稍微提升,产能就跟不上;这个点之后,稍微扩产就会产能过剩(当然不是所有行业过 30% 就一定过剩)。带着"产能过剩临界点"的框架去跟踪,就会拿足够多的数据去验证,甚至预判一些数据做情景假设,看现在像不像过了临界点的状态。

**而不是把一切都交给他人**:别人跟踪到增长了我就进,别人发现数据不好了我再出来。那你——

> 活该在行业刚开始有趋势性变化的时候赚不到钱,也活该在行业趋势向下的时候亏钱,更活该在行业趋势成型的过程中被小的数据扰动振下车,最后再以更高的成本上车。

市面上存在大量与 C 类似的基金经理,因为升任基金经理之前,C 大概率是个优秀、无偏、跟踪细致的研究员,更容易被提拔。

### 筛选基金经理的核心

> 我们筛选基金经理,不看他过去扔硬币猜正反对了多少次,而是看他有没有找到独属于自己的"正面 60%、反面 40%"的扔法,然后不假思索地赌正面。

**怎么知道一个基金经理有没有想清楚?** 答案是:带着合适的问题去面对面访谈、去对线、甚至去挑刺。这既需要访谈者自己有专业能力,也需要能聊得到基金经理。

### 公开资料能看出基金经理水平吗?不可能

公开材料**都**没用(是"都",不是"大都"),因为公开材料里每个人都是"长坡厚雪"——有人会滚出雪球,有人注定雪崩。只看别人的 PPT,必然选不出好产品。

- **公开宣传的投资理念没有意义**:真正有意义的不是理念,而是隐藏着魔鬼的细节。公开材料不会展示细节——写 PPT 的老师不了解细节,基金经理自己可能也想不到该如何表达细节。再说,被重点观察的细节,还是细节吗?
- **基金经理的观点没有意义**:投资从来不靠预判,而靠应对。观点承载的往往是和投资无关的信息——比如一个基金经理可以热情地表达自己多看好人工智能,但没有一家相关公司入他法眼。
- **基金公司的平台价值更没有意义**:决策不是平台行为,而是个人行为。平台不太容易形成投研助力,但拖后腿的实在太多(涉及投研沟通、激励机制、投资总监人品等)。另外,平台的渠道战略(最近要推什么产品)也是大家买基金亏钱的主要原因。**所以平台的最大价值,是不要有太大的负贡献。**
- **季报、中报、年报里的观点**:甚至还不如公开交流时口述的理念有意义,因为季报观点基本都要从绝大多数基金经理毫不在意的宏观因素讲起,基本都不是人话,人话也会被合规毙掉。
- **唯一有意义的是前十大重仓股**:因为这是基金经理给出的、最贴近真实想法的答案。但我们没法只通过"重仓股是谁"来窥探思路,只能以此为线索去访谈。

### 一个前提

我不讨论"长期持有还是短期参与""价值还是成长""大盘还是小盘""老将还是新锐""行业基金还是全市场基金"——因为这些全都建立在一个大前提之上:**基金经理能赚到实力钱,而不是运气钱。**

## 二、如果你要管好基金

### 与产业之间的"次元壁"

首先要理解一件事:我们作为投资研究人员,和产业之间隔着一道**不可逾越的次元壁**,我们做的很多事都是在和这道壁作斗争。

- 一个人哪怕产业研究做得再深,和天天泡在产业里的人相比,深度可能也远远不够,核心就是**细节**——产业里的人觉得天经地义、不需要讲的东西,对投研人员可能就是彻底的知识盲区。
- 产业里跑出来做投资的人,也不一定能跨过这道壁。就如同作者从投研一线跳出来做基金研究,也会丢失不少信息。

> 我们唯一能做的,就是挖掘一些产业当中连我们这些"外行"都能抓住的"确定性"。

作者把"如何管好基金"拆成两个话题:**提问题**和**求甚解**。

### 1. 提问题:想清楚一个命题,需要哪些更细小的问题来支撑

举例:基金经理说"我们买 XX 股份,是因为它们的 XX 是从 XX 采购的,成本比竞争对手低,形成了壁垒"。那么他至少应该探究过很多问题:

- **关于对手为何不跟进**:竞争对手没去采购,是因为不知道?还是不喜欢?还是这个老板有特殊资源?
- **关于老板的风险偏好**:如果这是老板几年前的兵行险棋,那老板日常爱冒险吗?这个行业需要经常冒险吗?后面还有什么颠覆性冒险?什么时候开始?
- **关于生意的本质(打铁 vs 挖矿)**:
  - 若是**打铁生意**——还有哪些卷王能跟老板打价格战?人家有多厚的家底?有多少人才储备和技术储备?
  - 若是**挖矿生意**——人家现在的矿比对手成本低多少?世上还有多少同级别品味的矿?分布在哪里?勘探和开矿难度多大?当地资源怎么获得?

### 2. 求甚解:答案要有足够有说服力、能梳理来龙去脉、还能顺着继续往下挖的证据

**反面示范一(用结果解释结果):** 回答"为什么这家公司竞争力更强"时,不要说"他家毛利率比别人高 X%,这背后就是竞争力的体现"——你只是重复说了一遍结果,没告诉我高毛利是怎么来的。

> 就好像我问你 XX 为什么会存在于世,你告诉我"XX 存在于世,自有存在于世的道理"。听君一席话,如同一席话。

**反面示范二(诉诸"访谈过专家"):** 回答某技术路线为何领先时,不要只说"我们大量访谈过专家"。那我只能跟你讨论"如何交叉验证、抓住假专家"这种玄学问题;我其实更想知道:你大量访谈之后,**哪些论点能说服你、也能交叉验证**。

**反面示范三(诉诸"我就是圈内人"):** 说"XX 的 XX 是我的 XX""我就是 XX 出来的"时,有没有想过——在北京你也能遇到"有朋友是 XX 的 XX"的出租车司机、"我一个电话就能给你叫来"的攒局人、"领导红头文件我亲眼看到了"的卖方?以及,作为你自己公司的员工,你们公司的经营数据你是否倒背如流?哪位副总和哪位副总在哪些业务上有路线或利益分歧,你是否清楚?

### 针对不同机会类型,你要想清楚的关键问题

| 你要抓的机会 | 必须想清楚的问题 |
|---|---|
| **挖掘好公司** | 核心人是啥样的?怎么做决策、怎么执行?关键环节的人才梯队是什么样的? |
| **0→1 的投资机会** | 怎么区分题材和真 0→1?质变背后是哪些量变?突破技术奇点之后哪些环节是关键堵点? |
| **1→N 的产业趋势** | 它到底替代的是哪些份额?谁是产能扩张的堵点?哪个节点是"30% 节点"?什么样的估值/单吨盈利预期算充分定价? |
| **区域经济机会** | 是哪位大员在主持招商?其过往从业画像?当地可调动的招商资源是什么?哪些自上而下的一票否决风险要考虑? |
| **消费趋势** | 解决了哪些人群的什么痛点?为什么这些人群的消费力/意愿在提升(可支配收入、人群数量、还是渠道变化)?有没有代表性产品可供跟踪?公司有没有想清楚渠道和营销打法?需要做好哪些工作,才能保证产品放到某量级不被口碑反噬? |
| **周期轮动机会** | 拐点之前的安全边际有多少?悲观预期 price-in 了多少?哪些关键条件变化会让周期见低回升更可视?拐点之后供需缺口有多大?供给约束有多强? |

### 结语

至于业绩、排名,作者说自己不看,大家也不用强调——

> 这世上哪有不在意回报率的基金经理啊,但这都是**结果**。我只在意**过程**。

最后,也祝大家 2024,大致顺利吧。
