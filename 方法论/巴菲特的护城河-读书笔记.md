# 带你十分钟读完《巴菲特的护城河》

> 作者：Florence（专栏「清雅微言」）
> 编辑于 2018-02-06 21:57

《巴菲特的护城河》剖析了巴菲特选股的原理，用大量商业案例讲清楚了什么是护城河、如何找到有护城河的优质企业、如何对企业估值并做价值投资。学会分析护城河，是掌握价值投资的基础技能。这篇读书笔记按五个环节，带你走进巴菲特的护城河世界。

---

## 一、认识护城河的概念及价值投资方法

**经济护城河**指企业抵御竞争对手攻击的**可持续竞争优势**——如同保护城堡的护城河。投资者确定长期投资目标时，首先要看企业是否拥有牢固的经济护城河，即能否在较长时期内实现超额收益，并随时间推移通过股价体现出超过市场大盘的盈利能力。此外，长期持有股票本身也能减少交易成本。

在股市中长期制胜的法宝，是按合理价位买进那些业绩超群的公司股票。落实这项策略的方法很简单：

1. 寻找能持续多年实现超额利益的企业；
2. 耐心等待，在股价低于其内在价值时买进；
3. 持有股票，直到企业出现衰退导致股价高估、或找到更佳投资机会时卖出——**持有期至少应达到 1 年，而不是以月数来衡量**；
4. 必要的话，重复上述操作。

这本书的重点是第一步：寻找能持续多年实现超额利益的企业。拥有经济护城河的企业，能在更长时间内为投资者创造更多经济利润；选中一家有护城河的公司，相当于买进了一条未来若干年内不会被竞争对手侵袭的现金流。

但要注意估值：**即使护城河再宽的公司，如果你以抬高的成本买入，也可能让你赔钱。**

---

## 二、学会辨别真假护城河

经济护城河是企业能常年保持竞争优势的**结构性特征**，是竞争对手难以复制的品质。

常见的**虚假护城河**——它们看似强大，却不构成结构性壁垒：优质产品、高市场份额、有效执行、卓越管理。

真正的护城河只有五类。下图把它们围绕"护城河"这一核心排开，构成识别护城河的完整清单：

| 序号 | 护城河类型 | 核心来源 |
|---|---|---|
| 1 | 无形资产 | 品牌、专利、监管（法定许可） |
| 2 | 成本优势 | 流程、地理位置、资源、规模 |
| 3 | 有效规模 | 市场容量只够少数企业有效经营 |
| 4 | 转换成本 | 客户更换供应商代价高 |
| 5 | 网络效应 | 用户越多，价值越大 |

逐一拆开看：

- **无形资产**——品牌、专利或法定许可，能让企业出售竞争对手无法效仿的产品或服务。三者强弱排序为 **法定许可 ＞ 专利 ＞ 品牌**；品牌最弱，因为它需要持续的广告、宣传费用来维护。
- **转换成本**——产品或服务让客户难以割舍，就形成让企业拥有定价权的转换成本，典型如银行、电话卡、金融服务机构。
- **网络效应**——有些幸运的公司能受益于网络经济，这是一种非常强大的护城河，可以把竞争对手长期拒之门外。它在**信息类或知识转移型行业**中更常见，前提是**网络必须是封闭的**。
- **成本优势**——通过流程、地理位置、经营规模或特有资产形成，让企业能以低于对手的价格出售。成本优势有 4 个来源：低成本的流程优势、更优越的地理位置、与众不同的资源、相对较大的市场规模。
- **规模优势**——是成本优势的一种。关键不是企业的**绝对规模**，而是**相对于竞争对手的规模**。规模带来的成本优势分 3 个层次：配送、生产、利基市场。

## 三、用动态发展的眼光来看护城河

有护城河的企业比没有护城河的企业更有投资价值，能在更长时间内创造更多经济利润。但护城河**绝非一成不变**，要用动态眼光持续检测它是否被侵蚀、宽窄是否变化。

技术变革、行业变迁、劳动力因素等都会影响护城河：

- **技术变革**会破坏企业的竞争优势。靠技术谋生的企业显然比销售技术的企业更担心，因为技术变革的影响不可预见。
- 当**客户群日趋集中**，或某个理性竞争对手已不再把赚钱当作唯一目标，说明企业的护城河已**危在旦夕**。
- **增长并不总是好事**。一个公司最好把主业赚来的钱返利于股东，而不是投入那些连自己都心里没底、不具备护城河的新业务。

## 四、发现护城河，寻找市场机会

总体而言，护城河在不同行业的分布很不均匀：

- 和硬件企业相比，**软件公司**里更容易发现护城河。
- **直接面对消费者的企业**往往难以形成竞争优势，如餐饮企业、零售商。拥有宽护城河的消费服务企业比例是所有行业中**最低**的，主要因为转换成本低。
- **为公司业务提供服务的企业**，拥有宽护城河的比例**最高**——它们能把自己的业务紧密嵌入客户业务，形成非常高的转换成本。
- **金融服务业**是另一个宽护城河的好去处，因为转换成本高、投入的资产大部分是粘性资产。
- **消费品领域**：可口可乐、高露洁、箭牌糖果、宝洁等都有较强的品牌；但品牌需要不断的广告投入和持之以恒的创新，这些都需要资金。
- **工业材料企业**很难看到护城河，因为这个行业成本的重要性高于一切；在这样的行业里给自己挖一条护城河绝非易事。
- **能源股**更类似金属商品，但护城河比想象中多：管道运输企业需要监管机构批准，天然气运输困难要靠管道，石油交易输出受到输出国组织的价格保护。
- **公用事业**，没有什么值得期待。

护城河之所以能增加企业价值，在于它帮助企业长时间保持盈利。任何一个企业的工作，无非是筹集资金，再投入项目、产品或服务去赚更多的钱。

**如何衡量资本的回报率？** 常见三种方式：资产收益率（ROA）、股东权益回报率（ROE）、投资资本回报率（ROIC）。很多企业不可避免要通过债券融资，因此要关注权益报酬率。ROE 有一个缺陷：企业可以在盈利能力没提高的情况下，通过**大量举债**推高 ROE。可把 **15% 作为衡量竞争能力的临界值**——只要企业的股东权益回报率长期达到或超过 15%，它就更可能比低于临界值的企业拥有护城河。

## 五、学会估值，该出手时才出手

判断一个公司是否拥有护城河，首先要检查以往的资产回报率。如果历史资本回报率保持强劲，就要进一步弄清企业如何延续这样的回报率，并运用前面的竞争分析工具判断护城河是否牢固、能维持多久。

买进股票的关键，是价格低于内在价值；而要判断价格是否低于价值，先得知道价值是多少。

**影响企业估价的 4 个重要因素：**

1. 企业未来所能创造的现金——**增长率**；
2. 实现这些预测现金流的可能性——**风险**；
3. 企业运作需要的投资额——**资本回报率**；
4. 企业将竞争对手拒于门外的时间——**经济护城河**。

**常用估值工具及其适用场景：**

| 工具 | 适用场景 / 要点 |
|---|---|
| 价格乘数 | 通用相对估值 |
| 市销率（PS） | 暂时亏损、或净利率有巨大改善空间的企业 |
| 市净率（PB） | 金融公司——账面净值更准确反映有形资产价值 |
| 市盈率（PE） | 主流盈利估值 |
| 市现率（PCF） | 评价现金流；用时最好从账面剔除商誉价值 |

**选股箴言：**

- **市销率**最适合暂时亏损或利润率低于潜能的企业。如果一家企业有提升利润的空间，又拥有较低的市销率，或许它就是你要找的便宜货。
- **市净率**适用于金融公司，因为其账面净值更贴近有形资产价值。但一定要当心**超低的市净率**，它可能说明账面价值本身有问题。
- 用**市盈率**时要看企业在顺境和逆境中的表现，想想未来会比过去好转还是恶化。
- **市现率**能帮你发现现金流出高于收益的公司，最适合"先拿现金后服务"的企业；但对于拥有大量计提折旧、将来需要替代的硬性资产的企业，它容易高估利润。
- 以收益率为基础去讲估值故事，可以直接把股票与债券等其他投资进行比较。

不管犯了什么错误，只要**最初买进股票的理由不再成立**，就没有必要继续持有。真正有意义的是你对企业未来的预测，而不是股价过去的表现。

## 附：识别护城河的完整判断流程（书中表 11-1）

把上面五个环节收敛成一张可操作的判定树——按顺序回答三个问题，就能给一家公司的护城河下结论：

**步骤 1：从历史上看，公司是否拥有可观的资本回报率？**
- 是 → 进入步骤 2
- 否 → 追问"公司的未来是否会不同于过去？"
  - 是 → 进入步骤 2
  - 否 → **无经济护城河**

**步骤 2：公司是否拥有下列一种或多种竞争优势？**（高转换成本、网络经济、低生产成本、无形资产）
- 是 → 进入步骤 3
- 否 → **无经济护城河**

**步骤 3：这种竞争优势有多强大？能长久维持，还是只是昙花一现？**
- 短（难以持久）→ **窄护城河**
- 长（可长久维持）→ **宽护城河**

一句话总结这套流程：先看**能不能赚超额回报**（资本回报率），再看**靠什么赚**（五类护城河之一），最后看**能赚多久**（持续性决定宽窄）。
