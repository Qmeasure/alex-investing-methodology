# 国内大模型中转站的竞争终局会是什么？

> **一句话结论**：所有建立在别人定价失误上的生意，终局都是一样的——要么失误被修正，要么需求被替代。中转站同时面临这两者。

---

## 一、套利基础：定价裂缝 + 注册门槛

我在前一篇文章中已经分析过，当前 Claude 的订阅套餐：

- 如果**不计算缓存命中**，大概可以让用户以 **0.74 折**的价格使用 Claude 的 token；
- 如果**计算缓存命中**，这个价格最低会被压到 **0.3 折**。

这个定价裂缝的存在，给了国内中转站一个**以极低成本转卖大模型 token 的套利基础**。

而 Anthropic 对大陆 IP 的持续封禁，又让国内用户注册 Claude 账户越来越困难——门槛一轮轮在抬高：

- 你需要海外手机号
- 需要干净的 IP
- 需要能过风控的支付方式

### 需求端没有萎缩，反而在膨胀

过去几个月的市场竞争格局已经证明了一件事：**用户最愿意为之付费的，是最高智能的大模型 token。**

- **不是最快的**——Grok Fast 4 主打速度，结果市场反响平平。
- **不是最便宜的**——DeepSeek 价格已经够低，但开发者该用 Claude 还是用 Claude。

用户甚至愿意为模型的高智能付出极高的溢价。这一点从 Claude Code 在开发者群体中近乎垄断级的渗透率就看得很清楚——Anthropic 最近披露 **Claude Code 的年化收入已经超过 25 亿美元**。

> 中转站就是在这个供需断裂带上长出来的生意。

---

## 二、中转站的完整武器库

但中转站手里的武器，远不只是"便宜转卖 token"这一项。它们至少还有三张牌可以打：

### 第一张牌：以次充好

arXiv 上 2026 年 3 月发表的论文《Real Money, Fake Models》对此做了系统性审计——

- 研究团队识别出 **17 个 shadow API 服务商**；
- 发现它们被 **187 篇学术论文**引用过，其中 **116 篇**发表在 ACL、CVPR、ICLR 等顶会上；
- 研究对 **24 个端点**进行检测，发现大量端点存在**模型替换行为**。

用户付的是 Opus 的钱，拿到的是 Sonnet 的输出，系统提示词里被注入了身份伪装指令，让低成本模型"演"成高端模型。博客园上有开发者专门写了 Python 检测脚本，标题就叫"花 Opus 的钱买到 Sonnet"。

> 这不是个别现象，是行业常态。

### 第二张牌：转卖数据

当前所有大模型公司的第一战略要务都是提升模型智能，而提升智能最关键的基础之一，是**获取足够多高质量的工作流数据**。

- 中转站每天流过的 prompt 加上 Claude 给出的高质量回答，构成了完美的**蒸馏训练对**；
- 用户的使用行为本身就是天然的质量筛选——好的回答继续用，差的回答换方式问——**偏好信号就藏在这些行为里**。

能从 Anthropic 这样的顶尖公司的模型上"薅"到高质量工作流数据，是所有国内大模型公司梦寐以求的事情。

### 第三张牌：退款套利

Anthropic 目前的退款机制是，**被封号的订阅账户全额退款**。部分中转站已经把这个流程系统化了——主动触发封号，拿到退款，等于零成本消耗了一整个订阅周期的 token。

---

以上就是中转站当前的完整武器库：

- 成本低到离谱
- 收入来源多元
- 进入门槛又极低——One-API、New-API 这些开源方案一天就能搭完，几千元启动资金就够

听起来是不是像一门完美的生意？

> **不是。我的判断恰恰相反。**

### 主要矛盾

> **这个市场的主要矛盾不是中转站之间的价格战——那只是表象。主要矛盾是：它是一个完全建立在平台定价漏洞之上的纯套利生意，而套利窗口正在被两侧同时挤压。**

- **供给侧**，Anthropic 必然收紧。
- **需求侧**，国产模型正在快速逼近"够用"的门槛。

中转站夹在两者之间，**没有任何结构性护城河**。

好，接下来我按时间线推演这个市场会怎么走。

---

## 第一阶段：血腥价格战，大量出清

当前中转站市场的核心问题可以用一句话概括：

> **太多人挤在同一条赛道上，做着完全一样的事情。**

进入门槛有多低？开源方案一天搭完，几千元启动资金，连个公司都不用注册。这意味着只要有利可图，就会不断涌入新玩家。

- 新玩家要抢客户怎么办？**降价。**
- 老玩家要守客户怎么办？**跟着降。**

于是价格被一路打到成本线上，然后穿透成本线。

### 价格战末期的"奇技淫巧"

当正常运营已经赚不到钱的时候，各种"奇技淫巧"就登场了：

- **以次充好**——用 Sonnet 冒充 Opus，用户付高价拿低配，省下来的就是利润
- **退款套利**——故意让账号被封，拿回全额退款，等于零成本获取 token
- **卖数据补贴**——把用户的 prompt 流水卖给大模型公司，用数据收入覆盖 token 亏损

这些操作的本质都一样：当正常商业模式跑不通的时候，就开始玩金融手段和灰色操作。**这是价格战进入末期的典型信号。**

### 供给侧同步收紧

与此同时，Anthropic 这边也没闲着。就在本周（2026 年 3 月底到 4 月初），几件事同时发生：

| 事件                         | 时间       | 影响                                       |
| -------------------------- | -------- | ---------------------------------------- |
| Anthropic 公开收紧 5 小时会话限制    | 3 月 26 日 | 高峰时段额度消耗速度大幅加快，约 7% 用户受影响                |
| Max 用户大面积投诉额度耗尽            | 3 月底     | 有 $100/月用户 1 小时耗尽额度，$200/月用户 19 分钟触及上限   |
| Claude Code 源码因 npm 打包错误泄露 | 3 月 31 日 | 51.2 万行 TypeScript 代码被公开，"解锁版"分支一天 10 万星 |
| 产品负责人 Lydia Hallie 发道歉帖    | 4 月 3 日  | 1.3 亿浏览，评论区一片骂声，多名 Max 用户公开退订            |

> Anthropic 连自家正常付费用户的额度都在收紧——你觉得中转站的日子会更好过吗？

### 庄家可以随时改规则

虽然 Claude Code 源码泄露给了中转站一些反检测的技术空间，但改变不了一个根本事实：

> **庄家可以随时改规则。**

以下措施中的任何一项落地，中转站的成本结构都会瞬间跳变：

- 把订阅从固定包月改成"基础包月 + 超额按量计费"
- 加入硬件指纹绑定
- 把退款从现金改成平台 credit

### 阶段结果

> **这个阶段的结果：80% 以上的小中转站会死掉或退出。**

能活下来的，要么有规模优势（账号池足够大，能分摊封号损失），要么有独特渠道（比如已经跟大模型公司建立了数据交易关系）。

这也是**用户体验最差的时期**——封号导致服务中断、模型偷换导致质量不可预期、中转站跑路时有发生。一片混乱。

---

## 第二阶段：市场重构，三层分化

经过第一阶段的血洗，存活下来的玩家会自然分化为三层结构。

### 上层：合规 API 经纪商

| 维度 | 内容 |
|------|------|
| **渠道来源** | AWS Bedrock / GCP Vertex 等正规渠道 |
| **合规性** | 完全合法，质量有保障 |
| **价格区间** | 原价 6-8 折 |
| **目标客户** | 企业、团队、对质量和稳定性有刚需的专业用户 |
| **利润来源** | 渠道溢价 + 技术服务费 |

这条路能走通，但天花板不高。本质上是个 TO B 的渠道分销生意，赚的是稳定性的溢价。

### 中层：大模型公司的"白手套"

这是三层结构里最值得深挖的一层。

表面上，它们是独立运营的中转站，提供极低价格甚至补贴。但背后，被 DeepSeek、阿里、字节等大模型公司暗中投资或控制。真实目的不是卖 token 赚差价，而是**采集数据**。

对用户来说，这是最便宜且最稳定的选择。用户不知道的是：

> **每一条 prompt 都在喂给国产模型做蒸馏训练。**

想想这个数据管道有多值钱——用户把最真实的工作需求发给 Claude，Claude 返回高质量的回答，这一来一回就是一对完美的训练数据。用户还帮你做了天然的筛选：好的回答他继续用，差的回答他换方式问，偏好信号全在里面。你去哪找一个比这更高效的数据标注工厂？

> **这是这个阶段最重要的结构性变化——中转站从"独立套利者"变成了"大模型公司的数据管道"。**

表面是中转站之间的竞争，实际上是国内大模型公司之间的**数据军备竞赛**——谁控制了更多的中转站数据管道，谁就能获取更多高质量蒸馏数据，模型迭代就更快。

"白手套"中转站的运营者可能自以为在做独立生意，但他们不过是大模型公司棋盘上的一颗棋子。大模型公司心里的想法大概是这样的：

> "你帮我从 Anthropic 的管道里抽取高质量数据，我补贴你的运营成本。等我的模型追上了 Claude，你的使命就完成了。到那时候，你对我还有什么价值？"

### 下层：灰色地下市场

- 继续用订阅逆向代理，跟 Anthropic 打永恒的猫鼠游戏
- 价格最低但极不稳定，质量完全不可控
- 服务最底层的价格敏感用户
- 类似 VPN 市场里的"小机场"——永远存在，永远不上台面

这层不值得多谈。它会一直存在，但永远是灰色地带，规模有限。

---

## 第三阶段：替代收敛，终局到来

前两个阶段讲的都是供给侧的变化。但真正决定这个市场生死的变量，不在供给侧，在需求侧——

> **国产模型什么时候能在关键场景追上 Claude？**

我把各场景的追赶进度拆开来看：

| 场景 | 当前差距 | 追赶时间线 | 追上后对中转站的影响 |
|------|----------|-----------|---------------------|
| 通用聊天 | 已追平 | — | 这部分中转站需求已接近归零 |
| 普通代码生成 | 差距很小（80-90%） | 3-6 个月 | 大量用户会迁移 |
| 复杂推理/规划 | 差距在缩小 | 6-12 个月 | 中等影响 |
| **Agentic Coding（Claude Code 级）** | **仍有显著差距** | **12-18 个月** | **中转站需求的最后堡垒** |

### 关键判断

> **Claude Code 级别的 Agentic Coding 能力，是中转站用户的最核心需求，也是国产模型目前差距最大的地方。**

一旦国产模型在这个场景达到 Claude 的 **85-90% 水平**——注意，不需要 100% 追平——三个优势叠加起来就足以驱动大规模迁移：

- **成本优势**——国产模型的 API 价格比 Claude 低一个数量级
- **合规优势**——不用担心封号、不用走灰色渠道、数据不出境
- **稳定性优势**——不会像中转站那样今天能用明天挂

这三个优势加在一起，对于 80% 以上的用户来说，足以抵消那 10-15% 的能力差距。

### 完整因果链

好，现在把三个阶段串起来看完整的因果链：

> 价格战打穿成本线 → 大量中转站死亡 → 存活者分化为三层 → 同时国产模型在关键场景逐步追上 → 用户大规模迁移 → 市场萎缩至当前规模的 10-15%

### 第三阶段的终态

- **中转站市场萎缩到当前的一成左右**
- 仅存的需求来自两类人：对 Claude 有极致要求的小众专业用户，以及纯惯性用户
- "白手套"型中转站完成数据采集的历史使命后逐步关闭——数据的边际价值已经被榨干
- 灰色地下市场继续以极小规模苟延残喘

---

## 终局思维的思考

很多中转站的运营者现在还沉浸在"流量暴涨、营收飙升"的兴奋中。我理解这种感觉——你搭了个系统，每天看着交易量往上涨，觉得自己找到了一门好生意。

但你需要问自己一个问题：

> **你手里有任何东西，是 Anthropic 改一行配置就没法拿走的吗？**

如果答案是没有，那你做的就不是生意，是套利。

### 最理性的策略

最理性的策略不是继续打价格战，而是趁现在还有流量和用户关系的时候，尽快往有真实产品价值的方向转型。比如：

- 做**多模型智能路由**——根据 prompt 复杂度自动分配最具性价比的模型
- 在**垂直场景**上做应用层的封装

总之，要把流量转化为用户关系，把用户关系沉淀为产品。

但坦率讲（我对此比较悲观，一家公司的 DNA 不是那么轻易就可以改变的），从套利商转型做产品的成功率，历史上非常低。

---

> **所有建立在别人定价失误上的生意，终局都是一样的——要么失误被修正，要么需求被替代。中转站同时面临这两者。**

窗口还在，但在关上。
