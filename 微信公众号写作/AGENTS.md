# 微信公众号写作

继承上级 `../AGENTS.md`(Vault 总规则)。本目录只放面向公众号发布的原创文章,不是方法论入库区,不走六字段 frontmatter 和「## 相关」SOP。

## 目录结构

- 每篇文章一个子文件夹:`YYYY-MM-DD-文章标题/`
- 子文件夹内:
  - `{标题}_公众号正文.html`:只有一个根 `<section>`、全内联样式,粘贴到公众号编辑器用
  - `{标题}_公众号预览.html`:带“复制到公众号”按钮的本地预览页,由正文生成
  - 文中用到的图片原件(公众号正文不能内嵌图片,正文里留“【此处插入图片】”占位框,发布时在后台手动上传替换)

## 生成方法

- 样式、配色、校验沿用 `~/.claude/skills/gzh-html-adapter`:正文改完先跑 `scripts/validate_gzh_html.py`,退出码 0 后再跑 `scripts/build_preview.py` 重新生成预览页。只改预览页不改正文是错的,预览页会被覆盖。
- 文章标题不写进正文(没有 `h1`),在公众号后台标题栏填写。
- 正文观点可引用 `../方法论/`、`../concepts/` 的笔记,但不改动这些笔记。

## 陷阱

- 行情数据要标明来源与截止日期;各家媒体报道的月度跌幅口径常不一致,能用行情数据自算的优先自算并核对。
- 公众号正文禁止 `img`/SVG/data URI,图片只能占位后手动上传。
- 不推送到公众号后台(草稿箱接口在 `~/Documents/api-playbooks/wechat-mp-guide.md`),除非用户明确要求。
